# dsh-ssh

为 DeepSeek Harness 右侧栏增加 SSH 远程面板，支持页面配置免密登录、交互终端，以及当前会话的 AI 通过 SSH 执行远程命令。使用本机 OpenSSH，无需在远端安装 DSH 或插件运行时。

## 安装

需要 Node.js 22.19+、支持自定义 Fetch 路由与 PTY 的 DSH（开发验证版本为 0.2.1-alpha.4），以及本机 `ssh`。远端需要 POSIX Shell。

```sh
npm install --legacy-peer-deps
npm run check
npm pack
dsh plugin --profile web add /绝对路径/dsh-ssh-0.2.0.tgz
```

桌面端可在插件管理页选择生成的 `dsh-ssh-0.2.0.tgz` 本地安装包。重启或重新加载插件后，在当前会话右侧栏的新增标签页中选择 **SSH 远程**。

## 使用

1. 已有免密配置时，可直接使用 SSH 配置中的 `IdentityFile`、`ProxyJump` 或 SSH Agent；加密私钥先通过 `ssh-add` 解锁。没有免密配置时，使用下方页面向导。
2. 在侧边栏填写主机别名、域名或 IP。用户名、端口和私钥路径可留空，沿用 SSH 配置。不要在主机字段填写 `user@host`，用户名使用单独字段。
3. 点击 **连接并授权当前会话**。连接成功后打开交互终端，可运行交互程序、按 Ctrl+C 或调整面板宽度。
4. 点击 **通知当前会话 AI**，再在会话中提出远程操作需求。原生 DSH 使用 `ssh_status`、`ssh_exec`、`ssh_read`、`ssh_stop`；Codex / Claude Code 使用通知中的本机 CLI。CLI 无需全局配置，凭据内容不进入聊天记录。
5. 点击 **撤销授权并断开** 立即使令牌失效，并终止插件管理的本机 SSH 进程和终端。会话卸载或宿主重启也会失去授权。切换会话、收起侧边栏或关闭 SSH 标签页会保留服务端连接；关闭终端按钮只关闭终端，不撤销 AI 授权。

**保存连接信息**只在当前浏览器保存主机、用户、端口和私钥路径，不保存授权、密码或私钥内容，也不会自动登录。不同浏览器不共享这些连接信息。

## 在页面配置免密登录

1. 填好主机、用户名和端口，展开 **配置免密登录**，输入一次远端账号密码，点击 **生成密钥并配置免密**。
2. 首次连接未知主机时，页面显示 OpenSSH 返回的主机指纹。请通过服务器控制台或管理员核实，再点击 **指纹正确，信任此主机**；拒绝时不会发送密码。
3. 插件在运行 DSH 的机器上生成无口令 Ed25519 专用密钥，位置为 `~/.ssh/dsh-ssh/id_ed25519_<连接标识>`；目录为 `0700`，私钥为 `0600`。同一连接重复配置会复用专用密钥，其他已有私钥不受影响。
4. 使用一次密码登录，将公钥追加到远端账号的 `~/.ssh/authorized_keys`，保留已有内容且避免重复追加，并将远端 `.ssh` 和 `authorized_keys` 权限设置为 `0700` / `0600`。目标路径是符号链接时会拒绝写入。
5. 独立验证使用该专用密钥登录成功后，页面回填私钥路径。点击 **保存连接信息**，再点击 **连接并授权当前会话**。免密配置本身不会授权 AI 操作。

密码只在配置期间保存在宿主内存中，不进入文件、命令行、环境变量、浏览器存储或 AI 消息；密码输入框在提交后清空。认证助手通过临时本机通道取用密码，配置结束会清理该通道。配置最多持续 2 分钟，取消、超时或会话卸载会停止受管进程并清空持有的密码。JavaScript 字符串由运行时回收，不承诺进程内存的物理覆写。

此向导要求 DSH 宿主为 macOS 或 Linux，远端允许 SSH 密码认证、公钥认证以及写入标准 `authorized_keys` 路径。键盘交互、一次性验证码和多因素认证不在本版向导范围内；不会修改服务器的 SSH 服务配置。私钥保存在 DSH 宿主上，使用手机页面配置时也不会把私钥写到手机。

远程访问 DSH 页面并提交密码时，应使用 HTTPS 或受信任的加密通道。使用跳板机时，跳板机本身需先配置密钥或 SSH Agent 认证；一次性密码只响应目标用户和主机的密码提示，不用于跳板机或私钥口令。

免密配置是持久的账号密钥设置，与会话授权分开：取消配置、撤销授权或重启 DSH **不会删除已生成的私钥或撤回已安装的公钥**；断线时不能保证远端安装步骤尚未执行。需要撤销免密登录时，请从远端 `authorized_keys` 删除对应 `.pub` 文件中的公钥。

## 执行规则

AI 可执行登录账号权限内的任意 Shell 命令，包括文件读写、部署、安装软件和删除。插件不提供提权；需要额外权限时，仍受远端 `sudo` 等规则约束。侧边栏 PTY 可处理交互，AI 命令入口不提供交互式密码输入。远端 Windows Shell 不在本版范围内。

每次 AI 命令是独立 Shell。使用 `cwd` 指定远端目录；跨步骤环境变量、`cd` 等状态应写在同一条命令里。远端目录切换失败会立即停止，后续命令不会在错误目录运行。终端则是持续的交互 Shell。

命令默认等待 1 秒（`waitMs` 可设置 0–10000），超时只返回运行状态，不中止任务；返回 `running: true` 时用命令 ID 和返回的 `offset` 继续读取。每个会话最多同时运行 8 个 AI 命令，最多保留 32 个任务结果。每个命令和终端保留最近 256 Ki 个 UTF-16 字符；更早的输出丢弃并返回 `truncated: true`。模型工具或 CLI 退出后，已启动的后台任务继续受当前授权管理。

连接失败和断线不会自动重试命令。退出码 255 或 `outcomeUnknown: true` 表示远端结果无法确认，尤其不能直接重试写操作。停止和撤销能保证本机受管进程停止；远端使用 `nohup`、服务管理器或其他方式脱离 SSH 的进程可能继续运行，需独立核查。

日常连接使用严格主机密钥校验和非交互认证，禁止 Agent 转发、配置中的端口转发、本地命令和已有控制连接复用。首次配置向导可在页面确认未知主机指纹并使用一次密码；已经记录但发生变更的主机密钥仍会被拒绝。SSH 配置中的 ProxyCommand / ProxyJump 是用户已有的本机可信配置，插件不会改写它们。

## 授权边界

授权只存于宿主内存，绑定会话和机器；原生工具从执行上下文取会话 ID，不接受模型指定其他会话。HTTP 路由由宿主连接层限制为已认证的所有者，再校验同源 JSON 请求。CLI 服务仅监听回环地址，以随机令牌绑定会话，令牌写在 `0700` 临时目录内的 `0600` 文件；CLI 无法调用授权接口或指定其他会话。撤销会移除文件并使令牌失效。

该授权隔离插件的操作入口，不是本机操作系统沙箱：拥有本机同一账号文件和任意命令执行权限的进程，本来就可调用本机 SSH，也可读取该账号的文件。不要把不可信的模型会话视为隔离的系统用户。连接信息和远端命令输出可进入当前会话记录；不要要求模型打印远端秘密。

本插件不会把宿主的本地文件浏览器或工作目录切换为远端文件系统；通过远程命令或交互终端操作远端。

## 开发验证

```sh
npm run check
npm run test:ui
npm run test:ssh
npm run test:host
```

测试覆盖参数校验、跨会话拒绝、登录失败、撤销竞态、PTY 生命周期、CLI 凭据和输出截断。`test:ui` 使用无界面 Chromium 和模拟远端，验证连接、终端输入输出、AI 通知、撤销和窄屏布局，并生成 `docs/ssh-*.png`。

`test:ssh` 在回环地址启动临时 sshd，以临时密钥验证真实命令、文件写入、CLI、PTY、缩放、Ctrl+C 与撤销，不修改用户 SSH 配置。它需要 `/usr/sbin/sshd`、`/usr/bin/ssh-keygen` 和本地 DSH 源码的已构建进程服务；源码默认位于 `../../deepseek-harness`，可用 `DSH_REFERENCE_ROOT` 指定。真实生产服务器仍需部署环境验收。

`test:host` 使用同一 DSH 源码中的真实 `defineTool` 检查原生工具合同、服务端接口与会话卸载，宿主上下文和远端输出使用测试替身。它不替代完整宿主应用的界面验收。
