# SSH 远程页面改造

## 已确认范围

- 使用 Sleek 设计并直接实现当前插件。
- 首页展示所有已保存主机的资源，不以 AI 会话授权为前提。
- 点击“新增主机”进入独立主机认证页，保留一次密码配置免密和已有密钥两种方式。
- 移除页面终端与入口。
- 资源查看连接与 AI 授权分离，每个会话继续最多授权一台主机；保存主机不自动授权 AI。

## 实现约束

- 继续兼容浏览器中 `dsh-ssh.connections.v1` 的已有主机资料，不保存密码、授权或私钥内容。
- 首页打开时刷新保存主机的资源；只执行固定的只读资源查询，不开放未授权的任意命令入口。
- 主机资源采集与新增认证不撤销已有 AI 会话授权。
- 沿用宿主主题和原有认证边界；深浅主题、320px 窄屏、禁用态及键盘操作均需可用。
- 页面不引入新的运行时依赖。

## 验收

- 空列表有明确新增入口，保存后返回首页，重载仍能显示保存资料。
- 所有保存主机均有独立资源状态；一个主机失败不影响其他主机。
- Linux 显示真实 CPU、内存与根磁盘数据；不支持的系统或不可用指标明确标记，不伪造资源数值。
- 新增密码认证保留指纹确认/拒绝、取消、错误重试、密码清空和专用密钥回填。
- 认证或资源查询成功不会授予 AI 权限；未授权执行仍被拒绝。
- 当前会话授权、通知 AI、撤销授权和任务停止均可操作，跨会话授权隔离保持有效。
- 页面与构建产物不加载终端组件，没有终端入口或隐式打开终端请求。
- 对实际页面做 WebKit/Chromium 深浅主题及窄屏截图核对。

## 实现与验证记录

已实现双页面、多主机采集、独立会话授权、密码/已有密钥认证和取消/失败/重试。Sleek 原稿中未展示完整的已有密钥与授权入口，实际实现补全这些状态；资源条使用真实采样，无虚构趋势图。字体和 Lucide 图标本地内嵌，无外部运行时设计依赖。

具体检查结果、真实 SSH 验证和已知限制见 `docs/validation.md` 的 2026-10-24 记录。
